Switch from vim-airline to lightline

Created2017-08-04|Updated2026-11-01
|Post Views:

Reason

vim-airline is an excellent Vim plugin which gives you a fancy status line and makes coding not that boring. However, recently I found it slowing down Vim’s start-up time.

I didn’t have this issue before, but now it takes at least 2 seconds to start a Vim session. I guess one reason may be that the /home directory is NFS-mounted and recently more people are using it.

I suspected the vim-airline plugin because Vim was freezing for 1s before the airline status bar showed up. After I disabled the plugin, Vim started up in almost no time. It might be too heavy.

Switch to lightline

However, I really like the fancy status bar. After searching, I found a very nice alternative - lightline.

Installation

Installation is very simple if you have a plugin manager like vundle or vim-plug. (BTW, I am using vim-plug now.) Just comment out the old one and add the new plugin.

Configuration

Actually, the default settings are good enough. I just did some simple configuration.

  • Change color scheme
  • Show git branch info (needs the vim-fugitive plugin)
  • Use powerline symbols
  • Show tabline and disable the GUI tabline

Misc

I managed to show buffers on the tabline, but it gets too long when you open many files. So I used the vim-bufferline plugin instead.

Result

Vim’s start-up time is very fast now and I still have a fancy status bar. I am happy with it ^_^.
