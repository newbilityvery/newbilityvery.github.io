My Vim Settings for verilog/systemverilog coding

Created2016-07-08|Updated2026-11-01
|Post Views:

Background

I started using Vim after I started working at my first company, because the platform was Linux and we were not allowed to install any software. Actually, it was not bad—I improved my Linux skills a lot on this limited platform.

I had tried to learn to use Vim before, but it was hard for me to remember the keys and switch between different modes. The platform forced me to use it, so I started with only basic operations like i, Esc, :w and so on. After figuring out the rules, it got easier and easier to learn new operations.

Most of the time, I am coding in Verilog. Unlike other software languages, it doesn’t have plenty of excellent tools/IDEs, free or paid, to use. Even for EDA tools that cost millions of dollars a year, their editing features are still bad. (Maybe they were not designed as code editors.)

However, after 4 years of tweaking, I think I have a relatively handy environment for coding in Verilog, at least for myself.

Tools

Emacs verilog mode

Yes, it is Emacs. I don’t know how to use Emacs, but its verilog-mode is amazing! It saves my life with top-level module connections and lots of tedious signal name typing. Check here if you are not familiar with it.

Even though we can use * in SystemVerilog, I still prefer the traditional way, because it is easier to debug the source code when signals are given explicitly.

Although it is an Emacs function, we can call it using emacs --batch {filenames...} -f verilog-batch-auto; and there is also a plugin to run it directly in Vim.

Vim

The Vim in my company was an old one (7.3), so I managed to compile the latest one in my home dir. Therefore, I can use new features such as relative line numbers and install newer plugins without compatibility issues. (I learned how to compile code here; previously I only knew apt-get.)

Vim Plugins

These are the plugins which are useful in Verilog coding.

  • Vundle

Vundle is a plugin manager for Vim. Just put the GitHub repo in your .vimrc to install and manage them.

Example:

All the plugins mentioned below can be installed like this.

  • verilog_emacsauto.vim
    With this plugin, you can use \a to expand all the verilog-mode autos (C-c C-a in Emacs) and use \d to delete the autos (C-c C-d in Emacs).

  • vim-airline

vim-airline provides a fancy status line for Vim. I switched to this after vim-powerline went into maintenance mode.

  • rainbow

This plugin gives different colors to different levels of parentheses, which makes complex code much easier to read.

  • indentLine

This plugin shows vertical lines at each indent level.

  • vim-systemverilog

Gives code highlighting and some other features for SystemVerilog.

  • tabular

Helps to align the code. For example:

after applying :Tabularize /=

For more details please check its GitHub page.

  • VisIncr

Makes it easier to create a column of increasing or decreasing numbers, dates, or daynames.

  • supertab

    It allows you to use for all your insert completion needs.
